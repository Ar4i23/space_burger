## 📖 О проекте

**Space Burger** — это полноценный одностраничный сайт-магазин космической бургерной с уникальным футуристичным дизайном. Проект создан с использованием чистого HTML, CSS и JavaScript без фреймворков, что делает его легким и быстрым.

Сайт включает в себя:

- Космический дизайн с анимированным фоном и неоновыми акцентами
- Полноценную корзину с сохранением товаров
- 📝 Форму оформления заказа с умной валидацией в реальном времени
- ️ Секцию доставки с интерактивной картой
- 📱 Полную адаптивность под все устройства

## Функционал

### Меню и каталог

- **6 уникальных бургеров** с космическими названиями
- **Фильтрация по категориям**: Все, Острые, Премиум, Большие
- **Адаптивные изображения** с `srcset` для быстрой загрузки на любых устройствах
- **Анимации появления** карточек при фильтрации

### 🛒 Корзина

- Добавление и удаление товаров
- Изменение количества (+/-)
- Автоматический подсчет итоговой суммы
- **Сохранение в localStorage** — корзина не теряется при обновлении страницы
- Toast-уведомления при добавлении товара

### 📝 Оформление заказа

- Форма с полями: имя, телефон, адрес, комментарий
- **Валидация в реальном времени** с визуальной обратной связью:
  - ✅ Зеленое свечение при правильном вводе
  - ❌ Красная тряска при ошибке
- Проверка формата телефона (+7/8)
- Проверка адреса (должен содержать буквы и цифры)
- Анимация загрузки при отправке
- Экран успеха с анимацией ракеты

### 🌌 Дизайн и UX

- Анимированный космический фон с эффектом зума
- Неоновые акценты и свечение элементов
- Плавные переходы и hover-эффекты
- Мобильное меню с анимацией "бургер"
- Кнопка "Наверх" при прокрутке
- Прелоадер при загрузке сайта

### Адаптивность

- **Десктоп**: 3 колонки меню
- **Планшет**: 2 колонки меню
- **Мобильный**: 1 колонка, оптимизированные отступы
